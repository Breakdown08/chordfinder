Как это работает

Нейросеть построена на Python и имеет собственное API. Для распознания аккорда, нейросеть ожидает на вход массив из аудио фреймов длительностью 1 секунда в JSON формате. Массив данных необходимо передать используя API и APIKey. Подробное руководство доступно в документации. APIKey можно получить в личном кабинете.
